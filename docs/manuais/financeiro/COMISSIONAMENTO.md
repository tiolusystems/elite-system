# Comissionamento

## O que esta tela faz

Define as pessoas e os percentuais previstos de uma venda antes do primeiro
recebimento.

## Antes de começar

- o pedido deve estar liberado;
- o pedido não pode possuir recebimento;
- a pessoa comissionada deve estar ativa;
- a conta deve possuir a alçada de comissionamento.

## Como executar

1. Pesquise o pedido pelo código ou cliente.
2. Abra o pedido e confira o valor total.
3. Adicione a pessoa, o papel e o percentual.
4. Repita para os demais participantes.
5. Confira o total distribuído.
6. Informe a justificativa e confirme.

## O que acontece depois

O sistema registra comissão prevista. Nenhum valor é liberado para pagamento
até que um recebimento do pedido seja confirmado.

## Bloqueios

Pedido bloqueado, pessoa inativa, percentual inválido, vínculo repetido ou
recebimento já existente impedem a alteração. A mensagem mantém o formulário
preenchido para correção.
