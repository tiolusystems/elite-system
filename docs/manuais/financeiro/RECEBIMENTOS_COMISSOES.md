# Visão financeira

O Financeiro está organizado por operação. A visão inicial é somente leitura e
os fluxos sensíveis ficam em telas próprias:

- [Comissionamento](COMISSIONAMENTO.md);
- [Recebimentos](RECEBIMENTOS.md);
- [Conta corrente de comissões](COMISSOES.md);
- [Ajuste manual excepcional](AJUSTE_MANUAL.md);
- [Relatório de comissões](RELATORIO_COMISSOES.md).

Cada área exige sua alçada individual. Cargo, perfil ou nome do papel não
concede automaticamente consulta, registro, pagamento, ajuste ou exportação.

## Sequência operacional

1. Definir comissionados no pedido liberado, antes do primeiro recebimento.
2. Registrar o valor efetivamente recebido com referência documental.
3. Conferir a liberação proporcional na conta corrente.
4. Registrar o pagamento até o saldo disponível.
5. Usar ajuste manual apenas para exceção documentada e autorizada.

Recebimentos, liberações, pagamentos, estornos e ajustes são fatos auditáveis.
Uma correção gera um novo movimento; o movimento original não é editado.
